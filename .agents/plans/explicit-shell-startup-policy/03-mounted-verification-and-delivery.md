3. Apply the same synthetic HOME profile/canary/marker procedure and explicit-source positive control from package 1. Verify execution and exit success, exact workspace cwd, preserved fixture HOME, no automatic profile marker/canary, correct command syntax and captured cap. 4. Mount equivalent default and explicit-login configurations in separate registries with identical component artifact/config inputs, then mount non-login. 5. Pass invalid mode to `MountStandard` and prove mount failure leaves no catalog tools registered. Supply valid unrelated dependencies. Inject prohibited policy JSON fields and prove the mounted decoder rejects them or they cannot change execution, consistent with its existing API.
6. Exercise timeout, in-flight parent interruption/process-group cleanup, explicit Env and both output streams through the resolved mounted executor in non-login mode. Use bounded fixture handshakes and the descendant/sentinel procedure from package 1, rather than a pre-canceled context alone. Do not use a live model, network provider or production database.

Every acquired plan must be released before closing its mount; use cleanup registration order or explicit teardown to avoid mount-close waits on retained leases. Cancel fixture contexts and terminate fixture descendants on assertion failure. Do not pass `t.Parallel` to tests that change the test process environment. Required shell/ripgrep prerequisites missing from designated CI jobs are failures, not accepted skips.
